# 📊 Análisis de Churn de Clientes - Telecom X

Este proyecto realiza un análisis profundo sobre la evasión de clientes (*Churn*) de la empresa **Telecom X**. A través de técnicas de Análisis Exploratorio de Datos (EDA) y procesos de ETL, se identifican los patrones críticos que llevan a los usuarios a abandonar el servicio y se proponen estrategias de retención basadas en datos.

## 📋 Descripción del Proyecto
El objetivo principal es entender por qué los clientes se dan de baja. El dataset analizado cuenta con información de **7,032 clientes** y **23 variables**, incluyendo datos demográficos, tipos de contrato, métodos de pago y cargos financieros.

## 🚀 Estructura del Análisis
El proyecto se divide en las siguientes etapas:

1.  **ETL (Extracción, Transformación y Carga):** Limpieza de datos, tratamiento de valores nulos y conversión de tipos de variables.
2.  **EDA (Análisis Exploratorio de Datos):** Visualización de distribuciones, perfiles demográficos y comportamiento de gasto.
3.  **Análisis de Abandono:** Identificación de variables con alta correlación con el Churn (contratos, antigüedad y precios).
4.  **Insights y Recomendaciones:** Hallazgos clave y sugerencias estratégicas para el negocio.

## 🔍 Hallazgos Clave
* **Punto Crítico:** Los primeros 6 meses de antigüedad son los más vulnerables para la deserción.
* **Factor Precio:** Los clientes que abandonan suelen tener cargos mensuales superiores a los **$79.7**.
* **Tipo de Contrato:** Los contratos "Mes a Mes" tienen una tasa de abandono del **42%**, mientras que los de largo plazo garantizan mayor lealtad.
* **Perfil de Riesgo:** Adultos mayores y clientes sin pareja muestran una mayor propensión a la baja.
